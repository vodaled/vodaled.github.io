# VodaLed — Landing Page

Лендінг компанії **VodaLed** (vodaled.org) — доставка води 18,9 л та льоду по Києву.

## Структура

```
vodaled/
├── index.html              # Головна сторінка
├── admin.html              # АДМІНКА: редагування цін/банера без JSON
├── serve.ps1               # Локальний сервер + API збереження (POST /api/config, /api/image)
├── config.json             # ВСІ динамічні дані (ціни, телефони, графік, партнери)
├── components/
│   ├── header.html         # Спільний хедер
│   └── footer.html         # Спільний футер
├── css/style.css           # Стилі (водно-льодяна тема)
├── js/main.js              # Логіка: підвантаження компонентів, рендер з config.json
└── assets/
    ├── logo.png            # Логотип VodaLed
    ├── products.png        # Фото продуктів (бутель + лід)
    ├── promo-banner.png    # Банер акції (замінюється через адмінку)
    └── ice/                # Фото позицій льоду (замінюються через адмінку)
```

## Як запустити

Сторінка підвантажує `components/*.html` та `config.json` через `fetch()`,
тому її потрібно відкривати через веб-сервер (не подвійним кліком по файлу).

**Варіант 1 — PowerShell (є на Windows за замовчуванням):**

```powershell
cd vodaled
python -m http.server 8080
```

**Варіант 2 — Python:**

```bash
cd vodaled
python -m http.server 8080
```

Далі відкрийте в браузері: **http://localhost:8080**

## Як змінити дані (без редагування HTML)

Усе змінюється в одному файлі — `config.json`:

| Ключ                | Що це                                        |
|---------------------|----------------------------------------------|
| `phone`             | Телефон ( він же Telegram та Viber)          |
| `phone_display`     | Телефон для показу на сайті                  |
| `telegram`          | Посилання на Telegram-чат                    |
| `viber`             | Посилання на Viber-чат                       |
| `schedule`          | Графік роботи                                |
| `prices.water[]`    | Ціни на воду                                 |
| `prices.water_banner` | Банер акції біля води: `image` (шлях до картинки) + `alt`. Приховати — видалити об'єкт або поставити `image: ""` |
| `prices.ice[]`      | Ціни на лід (куб, преміум, краш, 1 кг). Поле `image` — шлях до фото товару (без нього картка без фото) |
| `prices.accessories[]` | Бутлі, помпи, кулери, холодильники для льоду |
| `bottle_price`      | Ціна нового бутля 18,9 л (у Hero-картці)     |
| `partners[]`        | Партнери для каруселі (`logo: ""` = кружок з літерою) |
| `delivery.area`     | Опис зони доставки                          |
| `footer.*`          | Тексти футера                               |

Приклад: додати новий вид льоду —

```json
{ "name": "Лід Гель", "description": "Холодоагент", "unit": "1 шт", "price": 120 }
```

додайте цей об'єкт у масив `prices.ice` — картка з'явиться на сайті автоматично.

## Адмінка (без редагування JSON)

Відкрийте **http://localhost:8123/admin.html** (працює лише через `serve.ps1`).

Можливості:
- телефон, Telegram/Viber, графік, ціна бутля
- банер акції: увімкнути/вимкнути, alt-текст, **завантажити свою картинку** (кнопка вибору файлу)
- вода/лід/аксесуари: назва, ціна, одиниця, опис, позначка «Хіт», **заміна фото льоду**
- додавання та видалення позицій

Кнопка **«Зберегти зміни»** відправляє `config.json` та картинки на локальний сервер.
Перед кожним збереженням стара версія копіюється в `config.json.bak` (і `*.bak` для картинок).
Зміни з'являються на сайті після F5. Сервер слухає лише `127.0.0.1` — доступу ззовні немає.

## Логіка замовлення

Кнопки «Замовити» відкривають модальне вікно з телефоном та кнопками
Telegram / Viber. Замовлення приймаються вручну по телефону чи в месенджерах.
